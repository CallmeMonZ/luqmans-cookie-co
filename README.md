# Luqman's Cookie Co. website

A static, mobile-first page for the Luqman's Cookie Co. vending machine. It is plain HTML, CSS and JavaScript with no build step, so it runs on GitHub Pages and also when you double-click `index.html`.

> A full beginner's guide (menu, sold out, baked-on date, votes, exam mode, Hall of Fame, editing from an iPad) is coming in Phase 3.

## Where to edit things
**Everything you'll want to change is in `config.js`.** You don't need to touch the HTML.

- Anything in `[SQUARE BRACKETS]` is a placeholder. Until you replace it, the page shows a striped "placeholder" style or a "coming soon" note, so unfinished bits are easy to spot.
- **Allergens:** leave `allergens: null` until the bakery confirms them. The page then shows "Allergen info coming soon — ask us". Never guess.
- **Badges:** set `soldOut`, `isNew`, `favourite` or `lighter` to `true` on a menu item to show its badge.
